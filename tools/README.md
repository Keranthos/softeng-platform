# 开发工具说明

本目录包含用于提升开发效率的工具脚本。

## 1. 代码生成工具 (generate_repository.py)

### 功能
从数据库表结构自动生成Go语言的Repository接口和实现代码，减少重复代码编写。

### 使用方法

#### 基本用法
```bash
# 从schema.sql解析表结构并生成代码
python tools/generate_repository.py <table_name>

# 示例：为 tools 表生成Repository代码
python tools/generate_repository.py tools
```

#### 高级选项
```bash
# 指定输出目录
python tools/generate_repository.py tools --output-dir internal/repository

# 指定schema文件路径
python tools/generate_repository.py tools --schema-file database/schema.sql
```

### 生成内容
- Repository接口定义（包含基础CRUD方法）
- Repository实现代码（包含SQL查询逻辑）
- 自动处理主键、字段类型、NULL值等

### 注意事项
1. 生成的是**基础代码模板**，需要根据业务需求调整
2. 生成的文件会包含 `_generated.go` 后缀，表示自动生成
3. 建议在生成后检查并调整：
   - 方法签名是否符合业务需求
   - 字段类型是否正确
   - 是否需要添加业务逻辑
   - 错误处理是否完善

### 示例输出
生成的文件：`internal/repository/tools_repository_generated.go`

```go
// Code generated by tools/generate_repository.py. DO NOT EDIT.
package repository

type ToolRepository interface {
    GetByID(ctx context.Context, resource_id int) (map[string]interface{}, error)
    Create(ctx context.Context, userID int, data map[string]interface{}) (map[string]interface{}, error)
    // ...
}
```

## 2. API文档生成 (Swagger)

### 功能
自动从代码注释生成API文档，提供可视化的接口文档和测试界面。

### 安装依赖

```bash
# 安装swag工具
go get -u github.com/swaggo/swag/cmd/swag

# 安装gin-swagger
go get -u github.com/swaggo/gin-swagger
go get -u github.com/swaggo/files
```

### 生成文档

```bash
# 在项目根目录运行
swag init -g cmd/server/main.go

# 生成的文件会在 docs/ 目录下
```

### 访问文档

启动服务器后，访问：
```
http://localhost:8080/swagger/index.html
```

### 添加API注释

在Handler方法上添加Swagger注释：

```go
// GetTools 获取工具列表
// @Summary 获取工具列表
// @Description 根据分类、标签等条件获取工具列表
// @Tags tools
// @Accept json
// @Produce json
// @Param category query array false "工具分类"
// @Param sort query string false "排序方式"
// @Success 200 {object} map[string]interface{}
// @Router /tools [get]
func (h *ToolHandler) GetTools(c *gin.Context) {
    // ...
}
```

### Swagger注释说明

- `@Summary`: API简要说明
- `@Description`: 详细描述
- `@Tags`: API分组标签
- `@Accept`: 接受的请求格式（json, form-data等）
- `@Produce`: 返回的数据格式
- `@Param`: 参数说明（query/path/body）
- `@Success`: 成功响应说明
- `@Failure`: 错误响应说明
- `@Router`: 路由路径和方法

### 完整示例

```go
// SubmitTool 提交工具
// @Summary 提交新工具
// @Description 用户提交新工具，需要管理员审核
// @Tags tools
// @Accept json
// @Produce json
// @Security Bearer
// @Param tool body object true "工具信息"
// @Success 200 {object} map[string]interface{} "提交成功"
// @Failure 400 {object} map[string]interface{} "请求参数错误"
// @Failure 401 {object} map[string]interface{} "未授权"
// @Router /tools/submit [post]
func (h *ToolHandler) SubmitTool(c *gin.Context) {
    // ...
}
```

## 使用建议

1. **代码生成工具**：
   - 适合快速创建新表的Repository代码
   - 生成后需要手动调整业务逻辑
   - 不要直接使用生成的代码，要经过review

2. **API文档生成**：
   - 在开发新接口时同步添加注释
   - 定期运行 `swag init` 更新文档
   - 前端开发者可以通过文档了解接口用法

## 常见问题

### Q: 代码生成工具生成的代码有错误？
A: 这是正常的，生成的是模板代码，需要根据实际情况调整字段类型、业务逻辑等。

### Q: Swagger文档不显示？
A: 检查：
1. 是否运行了 `swag init`
2. 是否在main.go中注册了swagger路由
3. 注释格式是否正确

### Q: 如何更新API文档？
A: 修改Handler注释后，重新运行 `swag init` 即可。
